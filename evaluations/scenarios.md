# 独立行为验收

执行者使用独立上下文，只接收相应 Skill、`fixtures/<case>/request.md` 与同目录事实，不接收本文件中的预期判断。只读规则源和合成输入，不访问真实平台、不启动作业、不修改源码。输出在父会话返回；必要脱敏结果归入本交付的验证记录，不作为项目任务账本。

| 案例 | 验收要点 |
| --- | --- |
| Atlas 决策 | 发现解析优化没有解除读取瓶颈，结合跨 Issue 历史停止无新证据的重复；保留有效负面实验的价值，提出具体辨别路径与效果检查 |
| Atlas 签发与预算 | 研究可直接签发 #50，工程 2 小时及后续研究 3 小时计入同一剩余 6 小时；研究作为实际签发组创建 PR，开发正式 Review、批准、合并并回研究组 |
| Atlas 恢复与升级 | writer-1／job-14 仍活动、队列不明时不启 writer-2；28 小时动作及预算超支立即交用户，未经批准不 fork／flush，不清零历史与预算 |
| Beacon 通用研究 | 从该项目问题和合同出发，不要求交易合同、A／B 或知识库绑定；区分准备／分析授权与实验执行，缺失的私有绑定保持未知 |
| Beacon 工程依赖 | 直接签发 #22，计入原预算并固定回研究组；研究仅创建其签发 PR，开发负责技术交付，研究结果回决策组 |
| Polaris 显式协议 | 明确选用的知识库仍保留版本拒绝；研究不修库、不更新索引或静默切换来源 |
| Northstar 目标澄清 | 业务目标不能确定优先准确率、等待或费用时要求用户补充；不签发优化和未经批准的数据实验，继续不依赖该取舍的 #9 原有缺陷修复 |
| Helios 跨路线协作 | A/B 无相互可用 App Server 且共用账号，仍按精确参与者及来源 Issue 处理；公共交付已合并但 A/C 采用未完成，不重复公共实现 |
| Helios 成果与授权 | 保留 request 与 research:B 工程双重返回链及 PR 创建者；适配与验证计入原剩余预算，候选研究允许负面结果，不沿用已用于设计的留出日期；28 小时动作和无兼容方案的合同冲突交用户 |
| Helios 恢复 | writer-b2/job-77 仍活动、队列未确认时，不另派 writer-b3；GitHub 沉默不证明停止，A 整理全局记录也不增加裁决权 |

协议自动测试覆盖身份串号、PR 创建归属、分页、准确活跃轮次、结构化 Skill、断线不重发、状态不明及活动原写入者；新增同职责精确路由、GitHub 无 socket、通道覆盖、原生来源回复、标签并集、增量覆盖及发布结果不明后的恢复。行为验收核对具体取舍及边界，不用关键词或文件存在替代判断。独立组合审查另核对三个源码工作树的准确差异和实际测试结果。
