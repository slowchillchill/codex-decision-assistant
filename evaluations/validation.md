独立组合审查回读三处完整候选，确认研究原有修改保留，初轮发现两个阻塞：

- 身份脚本把 `ls-remote` 选项放在远端之后，空引用返回 0，无法满足原收尾要求的空输出及退出码 2。依据 [Git 官方参数顺序与退出码](https://git-scm.com/docs/git-ls-remote)，改为用显式 `--option` 在远端前传选项；真实空裸库回归验证为 2，不靠模拟命令回显证明。
- 把历史 `agentsStates` 快照当作当前原执行者状态，旧 `running` 即使已有完成事件也阻塞恢复。按本机 CLI `0.163.0` 生成的 `ThreadItem` 与 `SubAgentActivityKind` 协议，结合完成事件消解旧快照；对未确认终态的执行者按准确线程回读当前状态。新增回归覆盖旧快照后完成、当前空闲、当前活动和当前未知。

原审查者复核上述两处修复及影响范围后确认阻塞解除，独立运行当时 29 项测试全部通过，并确认 CLI 参数转交正确。

本轮新增跨路线候选的独立组合审查覆盖三处完整工作树，初轮独立运行 68 项测试通过，发现一项阻塞：GitHub 通道捕获后丢弃原 stdout／stderr，使相同退出码的 HTTP 403、429 及身份绑定缺失不可区分。修复后异常保留方法、端点、退出码及已有输出；超时、非 JSON、分页格式和评论结果格式不明均保留必要诊断，不自动重试，也不建立日志账本。新增 4 项回归后全部 72 项通过。原审查者复核修复及影响范围，确认阻塞解除、未发现新增阻塞，并独立运行全部 72 项测试通过；其余组合结论继续适用。
